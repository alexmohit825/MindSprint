# MindSprint (Book Summaries & Cognitive Intelligence Platform)
### Premier Commercial Executive Book Synthesis & Visual Mental Models Platform

MindSprint is an enterprise-grade book synthesis and cognitive intelligence application designed to outclass traditional 15-minute summary apps like Blinkist and Shortform.

---

## 🌟 Key Capabilities
- **The 3-Tier Depth Switcher**:
  - **The Spark (1 Min):** The executive thesis, the 30-second bottom line, and 3 golden rules.
  - **The Core (15 Min):** Chapter-by-chapter structural breakdowns, operational insights, and mental model diagrams.
  - **The Masterclass (40 Min - Shortform Killer):** Full dialectic critiques, author blind spots, counter-arguments from opposing thinkers, empirical case studies, and an actionable implementation playbook.
- **Infinite Real-Time Book Synthesizer:** Zero catalog limits. Synthesize *any* non-fiction title on Earth on-demand via Gemini 3.8 Flash with edge caching.
- **Natural Studio Voice Audio Narration:** Fluid synchronized playback, speed controls (0.75x–2.0x), and background audio.
- **Interactive Mental Model Studio:** Visual 2x2 matrices, habit loops, compounding exponential curves, and flywheel models.
- **Executive Quote Card Studio:** Export luxury typographic cards in Obsidian Gold, Swiss Minimal, or Editorial Serif for social media or presentation decks.

---

## 🛠 Tech Stack
- **Web / Edge:** Vite 6 + React 19 + Tailwind CSS + Lucide Icons + Cloudflare Workers / Pages
- **Intelligence Engine:** Google Gemini 3.8 Flash (`models/gemini-3.8-flash`) with structured JSON schema
- **iOS Native:** Swift / SwiftUI + AVAudioEngine standard Float32 audio format + StoreKit Review Hooks
- **CI/CD:** GitHub Actions on `macos-15` (Xcode 16+) for Ad-Hoc 1-Tap Safari OTA and App Store Connect TestFlight delivery
